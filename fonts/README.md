# 字体来源与许可

本目录的字体**不适用**仓库根目录的 MIT 许可，各自遵循下列条款。

| 文件 | 字体 | 许可 | 来源 |
| --- | --- | --- | --- |
| `SourceHanSansCN-{Regular,Medium,Bold}.ttf` | 思源黑体 Source Han Sans | SIL OFL 1.1，见 `OFL-SourceHan.txt` | [adobe-fonts/source-han-sans](https://github.com/adobe-fonts/source-han-sans) |
| `SourceHanSerifCN-Bold.ttf` | 思源宋体 Source Han Serif | SIL OFL 1.1，见 `OFL-SourceHan.txt` | [adobe-fonts/source-han-serif](https://github.com/adobe-fonts/source-han-serif) |
| `JetBrainsMono-Regular.ttf` | JetBrains Mono | SIL OFL 1.1，见 `OFL-JetBrainsMono.txt` | [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono) |
| `iconfont.ttf` | LapisCV 图标子集 | MIT，随 LapisCV 分发 | [BingyanStudio/LapisCV](https://github.com/BingyanStudio/LapisCV) |

OFL 1.1 允许自由使用、嵌入、修改和再分发，但要求：随附本许可副本、不单独售卖字体本身、修改后不得沿用保留字体名（Source、JetBrains Mono）。本仓库原样分发未经修改的字体文件，符合上述条件。

PDF 导出时 Chrome 会把用到的字形子集化嵌入文件，这属于 OFL 明确允许的嵌入用法。
